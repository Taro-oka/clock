# clock

## 動機
AI や React などのライブラリを使わず、Vanilla JavaScript で時計を作った。

昨今はフロントエンド技術や AI の進歩によって、Vanilla JS / CSS / HTML を直接触る機会がないどころか、コードを書くこと自体ほぼなくなってしまった。

そこで今回は、あえて以下の条件で時計を作ってみた。

- React などのライブラリを使わない
- Tailwind などの CSS フレームワークを使わない
- AI を使わない
- エディタの AI コード補完もオフにする
- 分からないことはひらすらググる

## 開発環境
CSS は直接編集せず、Sass コンパイラーを起動した状態で SCSS を編集。

## デプロイ
Netlify にデプロイ。

https://my-clock-ui.netlify.app/

## 感想
シンプルな実装でも、想像以上に時間がかかった。

特に CSS は難しく、コードのようにログや明確なエラーが出ないため、試行錯誤が多かった。
JavaScript では `this` の扱いで一度つまずき、基礎を見直すきっかけになった。

全体として、とても楽しかった！AI到来前の手でコードを書いていた感覚を思い出し、恋しくなった。大変だったけど、あの頃に戻りたい気もする（たった数年前のことだが...）
